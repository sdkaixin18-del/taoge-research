# 第120课：1月极弱回顾

**本课最值得带走的思路：极端行情里，熟悉标的和旧支撑不能抵消共同压力；观察解除要盯压力源是否改变，而不能只数“已经跌了几天”。**

## 核心洞见

### 1. 环境变化会改变平时熟悉的风险尺度

**重点：原来习惯的一两个点波动，在极端下跌中可能很快被放大。**

00:02—02:40，桃哥以朋友参与中视传媒、东田微的经历引入：只看个股逻辑和心中支撑，承受大幅回撤后又在恐慌中卖出，随后修复，心理压力很大。这是作者转述的经历，没有完整账户记录。

03:06—06:12，他将一字跌停、正常跌停和普通大阴线分层，认为突发成片一字跌停会传导到更多股票，波动速度与幅度也随之变化。他用平时做T的卖出、接回习惯作反例：仍按旧幅度接回，可能很快遇到更大的下午回落；同时补仓会进一步增加资金损失。

**我的理解：案例中分别记录波动变化与仓位变化。** 看实际振幅、下跌速度、成交与总仓位，而不把“5倍、10倍”当固定参数；也不因后来反弹，就忽略此前的流动性和持仓承受能力。

### 2. 一次短修复结束后，可能又出现新的压力源

**重点：前一批最弱股打开，不等于之后不会再有新的事件与负反馈。**

06:16—09:20，他回看1月22日压力、23—26日修复，以及月底再次下跌的过程。长江投资和上海自贸区题材在前一轮压力解除前已有走强，后续得到整体反弹助力；月底新的业绩等事件与高位股回落又叠加，使环境重新转弱。

这段回看说明，抢跑、解除、跟随反弹和再次恶化，应分别记录。只把1月当作一段连续下跌，会遗漏短修复；只记住那几天修复，又容易忽略后来条件变了。

**由此延伸：把事件和压力股按批次维护。** 每天保留新增、持续、打开与退出观察的对象，记录当时依据，避免一直盯着已经不再代表主要压力的旧名单。

### 3. 反弹预期没有兑现，本身会改变后续风险

**重点：第五天或指数短时翻红，都不是压力解除的充分条件。**

09:22—12:52，桃哥通过低换手、竞价成交等识别持续弱势对象。2月2日早盘市场一度尝试修复，但美吉姆、贤丰、合力泰等仍弱，随后再度恐慌；周末之后下跌继续。他希望读者注意，等到的反弹没有兑现，不能只沿用原来的时间预期。

13:08—15:48，他再比较2月6—8日：较大市值指数先被拉起时，最弱小票仍未打开，市场内部有明显差异；到8日，他将竞价承接变化与压力股打开，作为终于转入强修复的观察依据。

**我的理解：同时观察压力源、干预覆盖范围与实际扩散。** 指数红了，仍要看自己的股票群体是否改善。最低换手只是课程的筛查经验，研究时要结合自由流通盘、竞价与盘中变化，不能单凭一项数字断言风险解除。

### 4. 修复也有自己的梯队，后续回调需要重新判断

17:18—20:18，桃哥将节前跌停梯队与节后涨停梯队作对照，提到信雅达、国脉文化、二六三及克来机电、东方精工等。其思路是，修复期间强势梯队可能形成助推，而连续上涨后的补涨、开板与回落，又会改变环境。

他据此解释为何3月预期回调时不愿继续拿一堆普通股票。**我的理解：解除与退出都应有记录。** 不能只研究抄底，也要检查上涨天数、领涨梯队与后排表现，以及原先修复判断何时不再适用。

## 对实际研究的启发

本课适合成为一个完整的状态转换案例：压力出现 → 短修复 → 新压力叠加 → 修复预期落空 → 分层改善 → 压力解除 → 强势梯队与后续回调。后续B站研究应逐日核对事前表述和真实操作，课程回看只提供待检验的解释框架。

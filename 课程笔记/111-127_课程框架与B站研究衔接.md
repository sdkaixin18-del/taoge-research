# 第111—127课：课程框架与B站研究衔接

**这17课可以先归纳成一条判断链：看清哪类股票处在什么环境，判断机会来自整体修复、行业主线还是特殊事件，再选能表达该判断的工具，最后检查买入、持有、退出和仓位是否匹配。** 同样是急跌低吸，背后的理由与持有周期可能不同。

第111—127课的逐课笔记已整理完成，入口见[课程目录](README.md)。本文是跨课程归纳，并将课程提出的问题连接到已有B站研究；不把课堂经验直接视为已验证的交易规则，也不代表本人学习状态已完成。

**后续整合进展（2026-10-17）：** 已累计重点复核41条B站视频，资料池补至10/16；补充连续日线与25张案例图，并以课程重建三条主线和三个专题，删除原视频模式子文件夹。请结合[交易模式系统总结](../桃哥模式/交易模式系统总结.md)、[K线与操作对照](../桃哥模式/K线与操作对照.md)阅读本页。

## 二、用六个问题还原他的决策

### 1. 他判断的究竟是哪一类市场？

先确认小盘、成长、红利、金融等观察对象，记录基准与行业权重，再谈强弱。[第111—114课](111_大市值策略线.md)与[第127课01:02—05:12](127_标的方向与容量选择.md)共同说明：上证上涨、普通小票改善、某个行业走强，不能相互替代。

**研究上的延伸：** B站视频每次说“市场好”“环境差”，都要补上对象和当时日期，避免用不相关指数解释持仓。

### 2. 当前处在哪个阶段，压力是否还在传导？

月份是他的历史比较背景，位置、成交、风险事件和压力股变化是当时的状态。[第117课00:26—02:10](117_一年第一阶段行情规律.md)强调月度结果与月内路径不同；[第120课06:16—15:48](120_一月极弱回顾.md)展示了短修复、新压力与最终解除；[第123课15:14—25:12](123_高低位极弱与压力判断.md)又讨论位置及政策变化如何改变传导。

**研究上的延伸：** 保留最初判断、预期落空、调整及解除的时间顺序。不能只用后来上涨，反推他事前已经判断对。

### 3. 这次机会依赖什么？

课程至少提出三类来源：普通股票的共同修复，行业或核心的额外驱动，以及特定事件、价差与成交结构。前两类见[第119课00:14—08:16](119_一年第三阶段行情规律.md)，特殊结构见[第122课](122_环境对手法的影响与独立结构.md)和[第125课](125_岭南转债与股债折价案例.md)。

**研究上的延伸：** 先按依赖条件分组，再比较同一手法。尾盘撬板、事件反核、股债转换即使都有“低买高卖”，也不能合算成一种策略的胜率。

### 4. 为什么选择这个工具和这个标的？

[第116课09:01—10:56](116_几个例子.md)提醒检查当前预期；[第127课05:14—12:04](127_标的方向与容量选择.md)用反面选择和政策案例强调工具匹配。宽基、行业ETF、核心个股与转债，反映的驱动、弹性和持有约束不同。

**研究上的延伸：** 每例同时保存首选、备选和不选理由。分别评价环境判断、行业方向与个股选择，不能把三者压成一句“看对了却没赚”。

### 5. 触发、持有与退出，是否支持原来的理由？

急跌提供价格余地，承接和预期决定是否继续研究；买入后还要经历隔夜、次日开盘和退出。[第116课00:22—01:53](116_几个例子.md)与[第122课27:04—32:38](122_环境对手法的影响与独立结构.md)分别提醒持有区间、转债日内与隔夜的区别。

**研究上的延伸：** 挂单、未成交、作者自述成交和可核对的行情分开记录；利润按实际或明确标注的假设进出价计算。底仓做T作为执行层，另看它怎样影响原有仓位和风险。

### 6. 条件改变后，他是否降低了参与强度？

[第126课02:12—11:32](126_环境适应与回撤心态.md)将适应环境与保护成果联系起来；[第127课20:10—21:08](127_标的方向与容量选择.md)还讨论精力和交易损耗。

**研究上的延伸：** 收集少做、减仓、暂停与放弃的证据，同时保留买早、选弱、踏空、补仓后继续跌等反例。模式的边界往往在这些地方更清楚。

## 四、后续每个模式应留下怎样的成品

每个课程研究单元维护一份“条件与决策说明”，连接成功、失败、未成交和主动放弃的案例。统一保存以下信息，具体底表与流程需求已合并进[总TODO第4—10项](../TODO.md)，通用底表与流程仍为待建，本次不因文档完成而勾选。

| 环节 | 要保留的证据 |
|---|---|
| 来源 | 视频链接、发布日期与涉及交易日期、原话或准确转述、时间点；课堂解释与公开视频操作分别标记。 |
| 事前条件 | 观察基准、自然月与实际阶段、位置、流动性、压力对象与事件、首次可见时间。 |
| 选择 | 机会来源、核心依据、首选与备选、工具权重及风格、预期与失效条件。 |
| 行动 | 计划、作者自述实际操作、仅观察、挂单未成交、主动放弃；买卖时间、价格和仓位缺失时留空。 |
| 后续 | 当天、隔夜、次日及完整持有路径，同期基准、费用、回撤、退出或判断调整依据。 |
| 结论 | 哪些观察支持原判断，哪些反例限制适用范围；行情事实、作者归因和研究者推断分别写清。 |

**研究完成的标准：能从原始证据解释“为什么此时做这类机会、为什么选它、什么情况下放弃、最后如何兑现”，并在反例中检查这套解释。** 缺少完整成交时，先完成决策过程研究，不制造账户胜率和总收益。

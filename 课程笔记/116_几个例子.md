# 第116课：几个例子

**本课最值得带走的思路：市场环境要落实到真实的持有区间和具体买点。弱市中，增加同类持仓、碰到支撑位或追到消息刺激，都不能代替对整体环境及个股当前预期的判断；判断小盘会修复之后，还要确认所选股票能否受益。**

本课承接红盘率与情绪的讨论，先讲弱市持有风险，再补充支撑位、消息股和题材退潮的例子。下面按洞见整理，课程经验与自己的延伸分别标明。

## 核心洞见

### 1. 当天上涨覆盖面，只描述了一段行情；持有风险还会延续到次日

**重点：评估一笔交易，要看从实际买入到能够卖出的完整区间。**

00:22—01:53，桃哥把前面讨论的当日红盘率，与普通股票买入后需要隔日才能卖出的场景连接起来。他强调，若小盘处于连续下跌中，当天买入后的回落之外，还要考虑次日竞价和盘中的变化。这里的红盘率描述相对昨收的涨跌，真实交易盈亏仍需按自己的买卖价格计算。

00:43—01:20，他作了两个假设：如果连续两天都下跌约2%，一直拿到第二天尾盘，就会经历更长的下跌区间；即使计划次日开盘就走，弱题材后排在当天冲高回落之后，也可能再遇低开。他用“计提”概括这些尚未反映在当天收盘结果里的持有压力。

这条思路的启发在于，**“明天一早就走”也是一段需要检验的持有安排**。当天走势、隔夜跳空和次日盘中表现，对不同退出方式的影响不一样。03:33—04:25，他再次提醒，前面的当日统计并没有包含这些后续路径。

**我的理解：案例记录应把买入当天、隔夜和次日持有三段拆开。** 除了指数与上涨覆盖面，还留下真实买点、当天收盘、次日开盘、最终卖点及时间，才能分清亏损来自追高、隔夜变化，还是继续持有。课程中的连续下跌假设用于说明风险怎样累积，不据此推算任一交易的固定胜率。

### 2. 增加同风格股票的数量，并没有自动改变共同的市场风险

**重点：一跌就多买几只小票，可能扩大了对同一轮小盘行情的参与。**

02:04—03:30，桃哥讨论连续下跌时“多买几个，总能碰到红的”这种想法。他用两只、三只股票的概率类比，反对没有独立理由地不断增加持股数量；随后回看2024年1月末的国证2000日线和分时，描述越跌越慌、再买几只、最后手里十多个股票的情形。

他真正要强调的是，多只普通小票仍可能一起受到小盘环境影响。如果没有针对各自事件、板块地位和相对强弱的选择，多买几只并未解决最初“为什么能在这个环境里赚钱”的问题。他据此提出弱市减少持股数量、重视优秀个体的偏好。

**我的理解：检查持仓时，除了数有几只，还要看它们是否依赖同一项行情判断。** 行业标签不同的股票，也可能都在表达“小盘马上反弹”；跌了之后继续加票，还可能同时增加总仓位。研究记录应分别保留持股数量、各股权重、总仓位和选择理由，比较时固定资金规模。

课程中的乘法类比不能直接用于计算组合盈利概率；这里保留的是辨认共同暴露的思路，也不把减少持股数量写成普遍有效的降风险规则。

### 3. 支撑位需要环境支持，熟悉一只股票也不能保证它止跌

**重点：个股图形看起来到了支撑位，还要说明此时为何有力量承接。**

05:54—07:24，桃哥补讲一个假设：自己预计小盘当天还会明显下跌，但指数才跌到约1%时，某只熟悉的普通股票已经靠近历史支撑位，于是想抄底。他借此提醒，不能只挑股票图形，却忽略自己对整体环境仍弱的判断。

06:33—06:50，他对照课件第20页的顶点软件、航天宏图和深信服：图中标出的横向位置，随后都出现了向下穿越。案例的价值在于，把“这里以前有支撑”和“这一次能否守住”分开；若市场压力仍在，旧位置本身不足以解释为什么会出现修复。

**我的理解：记录支撑位时，也留下当时对市场、板块和个股承接的判断。** 支撑是一个待观察的位置；若计划参与修复，应写清预期修复的原因、需要观察的变化及原判断失效的条件。课程没有给出统一的支撑价位、指数安全阈值或止损线，本课不补造这些执行规则。

本地配图：[视频06:30，三只股票的支撑位对照](../课程视频/116_分析素材/0390.jpg)（仅本机可看）。

### 4. 消息刺激抬高了买价，却未必足以改变全天及隔日的压力

**重点：有消息、早盘拉升，与自己能从这个买点盈利，是不同的问题。**

07:26—08:17，桃哥用课件第21页的华软科技、首华燃气说明弱环境中的追高风险。华软的分时先明显冲高，随后一路回落；首华燃气的日线也留下较长上影。他关注的是，若上涨缺少足够持续的驱动，追高者会在原有市场压力之外，多承受从高买点回落的损失。

这与第一条连起来看，研究上应同时检查当天回落与隔日兑现。只看收盘相对昨收跌了几个点，可能低估高位买入者经历的损失。

他也保留了例外。08:19—08:58，视频展示2024年3月27日深城交分时：早盘下跌，盘中在他所述的深圳低空经济消息出现后急拉，尾盘仍有回落；他又比较同属低空经济的万丰奥威。他将后续继续走强解释为题材预期足够强，而不是说所有消息股都能抵抗弱市。

**由此延伸：事件研究要保存消息出现时间，以及出现前后的价格路径。** 再比较核心股、同题材跟随股与小盘基准，检查强势是否持续、是否扩散。深城交案例中的新闻内容与出现时点来自讲师回述，本次未取得原始消息记录，不把回看结果直接写成事前可执行的买点。

本地配图：[视频08:00，冲高回落例子](../课程视频/116_分析素材/0480.jpg)、[视频08:30，深城交盘中变化](../课程视频/116_分析素材/0510.jpg)（仅本机可看）。

### 5. 核心股也有预期兑现的时候，看对指数反弹仍需检查标的所处阶段

**重点：过去很强、曾是热点核心，不代表现在仍适合表达市场修复的判断。**

04:07—04:56，桃哥用2023年9月赛力斯作口头例子，提出弱市更关注有突出预期的个体，例如行业涨价、销量变化或新方向。他关注的是能说明自身驱动的股票，而不是随意挑几只等待普涨。

09:01—10:56，他用掌阅科技作更具体的反面观察：回看2024年3月27—29日，将其与国证2000叠图。掌阅曾随小盘反弹，但到29日未继续跟上；桃哥把这种分化解释为Kimi相关题材的预期已经兑现、个股位置较高，随后出现补跌。

这与第111课“看对反弹、选错受益方向”相连。本课进一步补充：即使选的是之前的强势股票，它所处的题材阶段也可能已经变了。桃哥提出关注仍有预期的主线，避免因为一只股票熟悉、前面涨过，就默认它还能继续跟随。

04:58—05:38，他还提醒，即使弱环境中有很强的板块，也不能直接推成广泛小盘都会受益；其对2000相关ETF的使用偏向阶段性修复。他在10:58—12:12用蓝科高新等例子预告后续强弱阶段和月份的区别，完整的月份规律留待后续课程展开。

**我的理解：候选池需要同时记录“当初为何关注”和“现在依据是否还在”。** 更新题材进展、兑现事项、相对强弱及失效条件，才能区分独立走强、跟随修复和退潮补跌。对“预期走完”的解释，也要尽量回查事前材料，避免只因事后下跌就补上理由。

本地配图：[视频10:00，掌阅科技与国证2000叠图](../课程视频/116_分析素材/0600.jpg)（仅本机可看）。

## 对实际研究的启发

第114课关注多数股票的环境，第115课辨认整体与涨停端的分化，第116课把这些认识落到了持有和选股。下面是据课程整理的观察顺序：

| 需要确认的内容 | 在研究记录中留下什么 |
|---|---|
| 预计参与哪类行情、持有多久 | 事前环境判断、对应基准、计划持有及退出时间 |
| 买点为何可能有效 | 支撑、消息或修复依据，当时承接表现与失效条件 |
| 个股当前是否仍有独立驱动 | 题材进展、核心地位依据、兑现事项、同期相对强弱 |
| 几只股票是否依赖同一判断 | 各股理由、权重、总仓位和共同风格 |
| 最后结果从何而来 | 买入至当天收盘、隔夜、次日持有及全部交易结果 |

例如，想参与小盘修复时，先留下环境判断，再检查候选是否仍有预期、买点是否已因追高增加回落压力；结束后按完整持有区间与同期基准比较。这样既能研究“为什么选它”，也能检查“为什么在这个时点参与”。

12:15—13:19，桃哥将粉丝提供的“冰点、沸点”情绪图，与通达信涨跌家数（画面代码880005）作对照，说明许多情绪展示可能来自相近的底层信息。**由此延伸，保留指标前先确认它的数据和用途**；图形接近可以提示重复，不能据此认定尚未取得的指标公式。

### 1. 给案例库增加完整持有区间与收益分解

- 解决的问题：把当天市场颜色与实际买入后的盈亏分开，识别当天追高、隔夜和次日继续持有的影响。
- 范围与核心字段：事前环境判断及时间、昨日收盘、实际或假设买入价格及时间、当天收盘、次日开盘、卖出价格及时间、费用和同期基准；实际成交与假设观察分开。
- 具体成果：案例页的持有区间收益分解及计算说明。支撑位失效、消息冲高回落、退潮股未跟随修复等案例沿用同一套字段。
- 完成标准：能从保存的价格重算各段及全程收益，区分相对昨收的涨跌与真实交易结果；不同退出安排注明各自观察区间，不把未成交价格当作实际收益。
- 来源洞见：第1、3、4、5条，视频00:22—01:53、05:54—10:56。关联总TODO第9、10项。

### 2. 给核心候选增加预期进展、兑现与失效记录

- 解决的问题：避免把历史强势和熟悉程度，当成当前继续走强的依据。
- 范围与核心字段：当前事件预期、消息来源及首次可见时间、进展与兑现事项、核心地位依据、与板块和小盘基准的相对强弱、失效条件、保留或移出时间及理由；沿用第115课热点与核心股记录。
- 具体成果：有版本和调整理由的候选池快照，连接热点板块对照页。
- 完成标准：能重建一个历史日当时可见的候选和依据，区分预期仍在、已经兑现及失效的状态，同时保留走弱或未兑现的候选。
- 来源洞见：第4、5条，视频08:19—10:56。关联总TODO第4项，连接已有第6、8项。

### 3. 在多股案例中记录共同风格、权重与总仓位

- 解决的问题：分清增加持股数量、增加资金投入及改变共同市场暴露。
- 范围与核心字段：固定日期的候选与持仓名单、每股选择理由、行业和市值风格、权重、总仓位、同区间表现及基准；比较不同组合时统一资金规模和观察区间。
- 具体成果：案例库中的组合对照页，连接已有股票观察池。
- 完成标准：可从保存的权重重算组合收益，说明多股方案是否仍依赖同一轮小盘修复；将组合整体盈亏、个股上涨覆盖面和全部个股均盈利分别记录。

## 简短补充

- 红盘率以昨收为比较基点，不等于开盘买入或任意时点买入的盈利概率；课程所说的弱市隔日风险是有环境与退出方式的讨论，不保证每次次日都更差。
- 即使假设单股盈利概率为10%且相互独立，乘出1%、0.1%描述的是两只、三只全部盈利的概率，不是组合整体盈利概率。实际股票还存在相关性，多股方案需结合权重与收益分布评价。
- 小盘指数的涨跌不能决定某一只股票必然破位或亏损；课中的正态分布与“结果注定”是讲师的解释框架。部分行情图实际使用国证2000，本文按画面标识记录，不能与中证2000当作同一指标。
- 对题材预期、核心地位及消息作用的归因，保留为课程观点；月份和“ETF只有投机价值”等表述反映讲师的阶段使用偏好，本课未提供完整统计或长期估值论证。历史图中的具体价位与涨幅不作为当前交易建议。

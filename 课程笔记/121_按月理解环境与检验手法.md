# 第121课：再讲一年十二个月行情规律

**本课最值得带走的思路：研究同一手法时，先把所处环境分开；全年的总盈亏可能掩盖某些阶段持续受益、另一些阶段反复受损的差别。**

## 核心洞见

### 1. 手法名称相同，适用条件可能已经变化

**重点：不能由一次成功，推成全年都能机械重复。**

00:02—02:58，桃哥反对笼统地问“明年小盘是不是都不涨”，用一年换衣服作类比，要求将月份和环境分开。他用美吉姆在不同阶段的截然不同走势说明，市场愿意给予的情绪溢价会变化。

他提出“大环境择时、板块择弹性、个股择日内最强”的顺序。**我的理解：归纳B站模式时，应同时写条件与动作。** “低吸”“隔夜”“追消息”只是动作，真正的模式还应包括当时的整体环境、方向、标的地位及退出安排。

### 2. 回测与账户归因，应先看条件分组再看总数

**重点：总收益好或坏，都不能直接说明方法在所有环境里有效或无效。**

02:14—02:58、10:24—11:02，桃哥要求将复盘、回测和账户盈亏按月份分开。他也说明“弱周期”有时只是对普通周期的习惯称呼，不能只根据名字判断每一天都同样弱。

**由此延伸：同时保存自然月与实际环境标签。** 每组记录样本数、收益分布、回撤、持有时间和执行偏差，另看原先条件之外的样本；标签需事前可观察，避免按后来赚亏倒推环境。月份是课程建议的分组入口，实际强弱状态仍需单独验证。

### 3. 弹性、空间与参与氛围，是不同的观察维度

03:00—08:14，桃哥重述三阶段，特别将2月的前期下跌空间、修复弹性、题材氛围连起来解释。他以美吉姆短期反弹和后来再下跌作提醒：短期投机上涨，不等于长期经营问题消失，也不能把阶段机会延伸到全年。

**我的理解：把“能涨多少”“为何有人愿意参与”“还能持续多久”分别记录。** 后续核对他的B站视频时，检验买入理由属于整体修复、独立事件还是交易结构，不用一个“行情好”涵盖所有原因。

### 4. 防守方向与普通股票，可以处在不同环境

08:56—10:18，他再用银行相关统计与小盘比较，认为在部分小盘较弱阶段，银行方向反而更强。这延续第111课的分化观察。

**由此延伸：给每种模式匹配基准。** 做小盘股时不能只看上证指数，做银行也不能直接套用小盘情绪；比较组合时保留行业、市值及工具差异。

## 对实际研究的启发

后续模式条目统一回答：**什么环境 → 什么触发 → 选什么 → 怎么参与 → 怎样退出 → 哪些情况失效**。随后检查B站原视频中这些条件是否真的出现，不能用课程中的一般表述替具体交易补造理由。

## 简短补充

月份规律是待检验的课程经验，不能保证某月一定有无风险或收益。银行表的34.72%在本课明确说是多个年份相加，不是复利；个股短期反弹也不改变其实际退市、经营或公告风险。

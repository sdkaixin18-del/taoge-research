## 学习安排

1. 从第111课开始，先学习111—127课；优先使用有字幕的版本。
2. 整理笔记时先阅读[笔记规范](课程笔记/笔记规范.md)，再复制[笔记模板](课程笔记/笔记模板.md)，以“课号_课程标题.md”命名。
3. 突出有启发的洞见，用案例和时间点展开，再提炼到研究基建TODO；定义或数字补充保持简短。
4. 课程笔记保留逐课上下文；跨课程总结集中维护在“桃哥模式”的课程模式正文及案例映射，不再按视频操作名称拆分模式目录。

Git同步研究文档和课程笔记。课程视频、课件、字幕及分析素材仅保存在本地，不进入Git。

# 强势回调与超跌反抽的筛选及连续K线验证

**程序已改为两类候选、日终筛选与盘中参与分开判断。10月8日重跑得到2只强势回调、15只超跌观察股，2只价格口径待核查。云南进入超跌池，但次日没有通过参与价格检查；澳弘进入强势回调池，却没有触发盘中下探条件。** 结果没有证明已经复刻桃哥的选股能力。

固定参数回放10月9、12、13、14、15日，全部19只、95个股票日期均保留。超跌候选出现3次先目标、8次先失效，另有7次收盘仍未触及两条边界；强势回调仅3个候选股票日期，样本不足。20个股票日期因未复权价格断点不判成功失败。当前预期和事件关系尚未完成逐条事前核查，因此没有把任何价格触发升级为完整情境合格信号。

## 课程判断怎样进入程序

第115课10:37—10:50要求复盘落到热点与核心对象；第116课05:54—10:56强调环境、当前预期和真实承接；第120课06:16—15:48与第123课11:54—26:22强调压力是否实际传导。由此把程序拆成四步：

1. **可交易性。** 真实成交额只检查示例规模是否可行，取消池内成交额名次淘汰；人气、核心地位和关注依据另存。
2. **价格结构。** 中期仍强、短期回落与没有满足中期强势定义的超跌分开；不因某股票次日涨得多倒填类别。
3. **情境证据。** 保存当前预期、影响关系、压力对象、来源、首次可见时间、有效期限与失效条件。未知不当成已经核查。
4. **盘中参与。** 完整K线出现承接、市场与压力观察对象缓和后，再按下一根开盘检查空间；选进池不等于可以买。

[10月8日视频00:42起](https://www.bilibili.com/video/BV1HfHQ6gE14/?t=42)中，桃哥将云南等尾盘回落归因于源杰，并给出次日条件性的修复设想。该盘后观点不能倒填为15:00已确认的输入。本轮云南的程序价格代理是同组亨通，不冒充源杰事件判断；程序支持在有事前记录时指定源杰等真实压力对象。实际归因和粗分主题也不能仅由价格相似证明。

## 固定的两类定义与验证口径

| 项目 | 本次固定的研究定义 |
|---|---|
| 交易容量 | 示例单笔10万元÷日均参与比例0.1%，要求20日日均真实成交额至少1亿元；不是仓位建议 |
| 强势回调 | 近20交易日收益为正且不弱于科技ETF515000，近5日收益为负 |
| 超跌反抽 | 不属于强势回调，近5日下跌至少1个事前ATR，距近20日最高价至少2个ATR |
| 环境与承接 | 当日先下探0.5 ATR；股票最近3根低点不降、收盘越过前根高点并高于VWAP；市场和压力对象同样不再创新低并收涨，同伴至少一半不再下跌 |
| 买价检查 | 完整K线确认后，下一根开盘重新计算每边10基点成本后的收益/风险，至少1.5；最多一次参与假设 |
| 目标与失效 | 目标固定为筛选日收盘；失效位为触发时最近3根低点减0.01元；不以全日最低点入场 |
| 先后与成交 | 同根双触不指定先后；一字价入场不假定成交；跳空按开盘重新判断 |
| 普通股票持有 | 日内只记价格路径，另列T+1下一交易日开盘对照；跨除权/派息口径断点不算未调整收益 |

窗口、ATR倍数、目标和成本等均为研究者操作定义，课程没有给出这些公式。科技ETF515000是宽泛科技市场参照，不是每个细分行业的完整指数。[基金官方资料](https://www.fsfund.com/fund/515000/fundDetail.shtml?tabIndex=9)

[研究协议](../选股程序/研究协议.md)和[当前配置](../选股程序/配置/反抽规则.json)给出完整条件。参数在新增分钟采集前封存，没有参数搜索、为云南设例外或事后放宽名额。实现中修正了价格断点仅提示却仍计算路径的错误；封存的选股及参与阈值不变，执行修正记录另存。旧实现、旧配置与旧演示包已移除。

## 数据口径与复现

原始资料为BaoStock不复权日线及5分钟线，19只股票加1个科技ETF参照；日线每只49个交易日，分钟每只288根，覆盖10月9—16日6个交易日，共5760根。主验证为前5日，最后一日补T+1对照。真实量额、历史交易/ST状态、请求、获取时间及原始字段均保留。

95个股票日期中68个存在至少一项日线与分钟OHLC差异，逐条输出。将20个已冻结参与计划的时点、目标和失效边界放到腾讯历史分钟K线上核对，20个先后标签一致；未混用两源量额，也未据此宣布整套触发条件跨源稳定。价格是事后下载版本，无法证明当时的实际发布延迟和修订历史。

未复权前收断点不能当作真实跌幅。例如德明利[9月29日权益分派实施公告](https://static.cninfo.com.cn/finalpage/2026-09-29/1225585295.PDF)披露现金派发与转增，中际[9月28日实施资料](https://disc.static.szse.cn/download/disc/disk03/finalpage/2026-09-28/23ac00cb-3b1f-4a3f-ae51-31e72e5fc53d.PDF)披露10月12日除权除息。当前程序在调整因子与权益处理尚未统一前暂停相应比较；本轮没有将公告的事前核查状态事后改成已完成。

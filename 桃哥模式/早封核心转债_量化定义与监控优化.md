# 早封核心转债的量化定义与监控优化

**先找到有当前事件依据的早封正股，等板块扩散增强其地位，再研究转债是否仍有可参与的价格。** 债涨幅小只是观察现象；机会来自次日预期在当天债价中的重估。这个分支继续归入[C03当前预期](交易模式系统总结.md#c03)与[C06股债联动](交易模式系统总结.md#c06)。项目层面进一步加入[事件Agent与市场风险](转债监控_事件Agent与市场风险优化.md)：消息发现前置，市场环境持续参与候选和退出判断。

课程依据为115课的热点与核心、116课的当前预期、122课27:04—32:38的正股、债与队友依赖；[10/16视频00:30—00:40](https://www.bilibili.com/video/BV1wNJ96MEFu/?t=30)提供保隆早封及次日一字预期的解释，原始依据见[保隆案例](低空经济股债联动_20261016.md)。下文数字门槛是2026年10月18日的研究定义，尚未独立检验，不是桃哥公开的机械公式。

## 分钟线怎样逐步形成机会

采用已保存的腾讯历史1分钟及5分钟行情。板块固定为保隆、万丰、中信、金盾、宗申、上工六股；评估保隆时剔除保隆自身，避免它同时充当核心和自己的助攻。篮子来自既有案例研究，不是全市场历史成分的完整重建。

队友强度统一为`当前涨幅 / 本股当日涨停幅度`。走过30%分别约对应主板上涨3%、20%涨停股票上涨6%，避免用同一个8%比较不同涨停制度。实盘分母须使用核验后的当日实际涨停价；本地样本的简化计算不扩用于ST、无涨跌幅限制或特殊除权情况。

## 可以量化的条件

先使用分层条件和原始字段，不把所有信息压成一个无法解释的总分。

| 环节 | 初始观察定义 | 数据边界 |
|---|---|---|
| 身份与事件 | 有效股债映射；分析时点之前已有事件依据，标出公司确认、技术映射或待证 | 时间、类别可存储；“唯一正宗”仍需公司或客户证据，公社关键词不能直接升级为事实。 |
| 市场环境 | A股与转债基准的短时方向、从当时高点回撤、股债共振及数据可信度，独立形成风险状态 | 市场防守时暂停新增，已有计划提前检查获利保护；不能只看正股和题材，具体状态见[重整方案](转债监控_事件Agent与市场风险优化.md#增加独立的市场风险层)。 |
| 早封 | 首次有效观察到涨停不晚于10:00；另记主题内相对上板次序 | 中途启动已封板只能写首次观察已封，此前首封未知，不能补成早封。 |
| 稳定 | 当前在板；最近至少10根连续有效一分钟线，低点与收盘都在涨停 | 缺口为未知。快照采样只支持“观察到的稳定”，不证明轮询间从未开板。 |
| 板块助攻 | 剔除自身，至少1只队友收涨停，至少60%队友走过自身涨停幅度的30% | 初版要求篮子完整，缺数据不算弱、也不算通过。10分钟、60%等只是待验证的种子参数。 |
| 债反映程度 | 最近30分钟范围、历史同时间成交响应、离已知压力位距离、同步溢价 | 不用“股涨10%、债涨2%”推算应补8%，也不以低涨幅推断无人关注。 |
| 债确认 | 沿用旧规则：10:00—11:00，完成5分钟收盘超过此前6根最高，量至少为此前6根均量1.5倍 | 每债只登记第一信号；连续几根通过不算多次独立机会。 |
| 价格合格 | 冻结当时已知目标、失效位及成本，计算参与上限 | 盘口深度及真实成交不足时保持待核，价格参考不等于成交。 |
| 次日预期 | 记录比早盘增强的证据：抢先封板、队友新增、稳定性及事件延续 | 可以形成证据状态，暂不能输出“一字概率80%”等数字。 |

10:30保隆债累计量已约为前6日同期均量4.01倍，说明成交关注存在；转股溢价约62.54%，并非锁定转股价差。规模、溢价和历史股性债性用于约束成本与容量，当前不设“必须小盘、必须低溢价”的淘汰线。计算依据见[候选扩展](低空候选筛选_20261016.md#为什么保隆债没有从开盘一路跟上)。

## 提前筛选的顺序

盘前准备股债基础表及已有事件关系，盘中让事件Agent按新消息追加带证据和可用时间的“事件—股票—队友”版本；行情程序持续检查市场环境。公社和用户链接帮助发现对象，公司公告核对事实与证券状态。股票有观察价值，不代表旧债仍可交易。

盘中从有债正股及事件池找早封者，再补看它的队友。**队友即使没有转债，也要进入板块统计。** 早封者获助攻后持续跟踪对应债，比较整理承接、已知压力与执行成本。排序依次看事件依据、相对封板次序、稳定性和助攻，最后看债剩余空间；不按事后最大涨幅认定核心。

本轮重算7组股债×48个完成时点，共336条特征记录。在09:45—10:35检查点中，只有保隆具有早封价格前提。声迅、广泰缺正股涨停，豪26、通裕也缺早封；航宇、豪美还缺本次事件核心依据。它们继续保留在[原成功、失败和未触发记录](低空候选筛选_20261016.md)，不因新过滤删除广泰的亏损路径。

“只剩保隆”说明本例机制表达更精确，不代表准确率已经提高。门槛在已知走势后提出，只能作开发案例；下一步要找完整前提相同、债却不跟或突破失败的新日期反例。

## 参与分预判和确认

**预判分支：** 09:45后可以开始研究；10:00—10:30看到早封与助攻持续、债仍整理。若参与，须当时记录入场价、已经形成的区间下沿、最长等待及退出条件。10:00入场只能用10:00以前的低点，不能倒用10:35的123.144。可把“入场后3根完整5分钟仍无确认，结束预判”作为独立待验证规则；等待候选不等于已经买入，也不能用后来的成功抹去早退出。

**确认分支：** 10:35产生完成信号，保留10:40收盘124.210作延迟参考。它比整理期贵，不能把10:00低价与10:35确认合成理想交易。实际参与还须核对当时卖价与深度。

用当时已知的早盘高点127.737作第一压力目标T，信号5分钟低点123.144作失效参考S，新增价格约束示例。假设参与参考E、单边不利成本c：

```text
净收益风险比 = [T×(1−c) − E×(1+c)] / [E×(1+c) − S×(1−c)]
要求至少1.5时，E上限 = (T+1.5×S)×(1−c) / [2.5×(1+c)]
```

| 买卖各自的成本情景 | 124.210至第一目标的净空间 | 净收益风险比 | 参与价上限，向下取至0.001元 |
|---|---:|---:|---:|
| 0，纯价格对照 | 2.84% | 3.31 | 124.981 |
| 各0.10% | 2.63% | 2.49 | 124.731 |
| 各0.30% | 2.22% | 1.53 | 124.233 |

费用与不利执行均为假设，不是个人真实费率。123.144是警报边界，实际退出可能更差，该比值也不是保证的盈亏比。10:45收124.801已超各0.10%情景的上限，应记“前提仍在、价格超计划”，不能把目标改成事后的145.159。若另有当时能解释的新目标，另建计划并保留旧计划放弃记录。

## 退出与失败条件

第一目标127.737是入场前已知的压力，可事先安排部分兑现；余仓再按独立保护规则跟随。实际一分钟线10:57首次触及它，证明存在触及，不能证明挂单成交；无比例与执行记录时不计算分批实际收益。

余仓保护可沿用旧例：完成5分钟收盘跌破此前3根低点即警报，下一根收盘只作延迟参考。实盘保护位只上移，不因后续下跌放宽。13:30—13:35体现债自身退出条件的作用，不等正股开板。更早的13:05—13:20，市场与转债基准已共同转弱，应增加环境风险与利润保护提示；债的价格破坏是后续确认，不是唯一退出依据。旧规则全仓延迟价格路径约+13.48%继续保留；它与第一目标部分兑现方案分开，不拼接收益。

| 类别 | 当时的条件 | 处理 |
|---|---|---|
| 事件判断失败 | 关键事实被否认、催化兑现后缺少新增预期、核心认定依据消失 | 撤销对应事件候选，保存更正来源及收到时间。 |
| 正股结构失败 | 封板后观察到持续开板、承接转弱；回封也未恢复助攻 | 降级或撤销；只记实际观察到的变化，缺口不算从未开板。 |
| 板块支持失败 | 剔除自身后助攻跌出门槛，且在连续两根完整5分钟中均未恢复 | 停止新增；已有计划复核，是否提前退出须事前约定。该去抖亦待验证。 |
| 市场转弱 | 股市与转债市场共同承压，即使正股和板块仍强 | 降低或暂停新增，已有计划检查兑现与保护；环境风险未必意味着题材被证伪。 |
| 债不响应 | 预判入场后达到约定等待时间仍无确认 | 结束预判，不能无限延长等待。 |
| 突破失败 | 完成5分钟收回原整理上沿下方，或跌破固定失效位 | 分别提醒突破未维持／固定失效，按预定计划处理，止损不下移。 |
| 价格不合格 | 前提仍强，但买价超过上限或已到第一压力 | 属放弃追价或兑现，不算事件判断被证伪。 |
| 债独立转弱 | 跌破保护位或失去可执行承接 | 可以先于正股开板退出；保隆午后是对应路径。 |
| 到时或数据异常 | 预定14:55结束；陈旧、缺口、证券状态无法核对 | 到时执行计划；数据异常标未知并暂停新增，不自动标作价格失败。 |

T+0提供当日退出机制，不保证退出价。20%是本例非上市首日涨跌幅限制；依据[上交所现行细则第五、六、十五条](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/trading/currency/c/c_20250606_10781040.shtml)。

## 对现有转债监控的具体优化

完整项目设计已重整为[事件Agent与市场风险优化](转债监控_事件Agent与市场风险优化.md)，对应私有监控0.7.1、提交`1c6f36e`。当前优先建设五个相连部分：

1. 主动新闻及用户链接入口，保留触板后的反查；每股每天一次的补充查询升级为事件与内容版本。
2. 一个有检索、核对和映射工具、超时及费用预算的事件Agent，将证据和可用时间写入SQLite；动态事件可盘中更新，不阻塞行情。
3. A股与转债市场的独立风险状态，先于个券破位提醒获利保护，模型积极解释不能覆盖固定风险规则。
4. 早封履历、无债队友、债确认、参与上限及活跃债持续状态；正股不再变化、或已跌离涨停时也继续核查债。
5. 根事件独立投递、阶段去重、完整留档与模拟验证，市场风险不等待题材摘要或父正股首报。

“事件待核”“市场警惕”“股债已确认”“价格超限”“已有真实持仓计划”分别保存。市场转弱不自动等于事件失败；价格条件满足也不表示已成交。普通早封与09:25一字开盘、采样快照与真实分钟线的复用边界继续保留，详见重整方案。

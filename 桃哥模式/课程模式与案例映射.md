## 二、18组K线资料分别承担什么角色

下表是课程问题与既有材料的研究对应，不能据此声称作者当时明确按某一课下单。“自述操作”也不等于取得了交割单；具体视频时间点、价格和已知缺失继续保存在案例正文。

| K线组 | 与课程的关系 | 行为与证据角色 | 能对照什么，尚不能确认什么 |
|---|---|---|---|
| [K01 东山精密](K线与操作对照.md#k01) | 执行层；C03局部对应 | 低吸、退出自述与跨日日线 | 修复后仍可能下跌，退出时间影响结果；当前预期和所有成交未完整复原。 |
| [K02 兆易创新](K线与操作对照.md#k02) | 执行层；C03选股比较 | 回补、加仓失败自述 | 较早卖价便宜不等于卖压解除；缺数量，不能算做T净贡献。 |
| [K03 上海港湾／巨力索具](K线与操作对照.md#k03) | C03同题材比较；与C04的位置承接问题作机制比较 | 两笔参与自述、不同留存反弹 | 不能由相同题材和打开动作推定相同质量；未完整重建事件来源及买点，不直接定为同一种事件交易。 |
| [K04／K14 德明利／563300](K线与操作对照.md#k04) | C02 | 压力观察与ETF参与分开 | 可看压力变化、7月回落及8月修复减仓；观察德明利不等于买入德明利。 |
| [K05 创业黑马／传智教育](K线与操作对照.md#k05) | C03；C02是当时背景 | 个体参与与队友观察 | 比较急跌个体与同方向强股；传智“顶一字”只保留为当时观察，不扩大到全天。 |
| [K06 康泰生物](K线与操作对照.md#k06) | C03；执行层 | 消息后参与、隔夜转亏自述 | 当天强势未保证次日兑现；标题、日内高点与真实收益分开。 |
| [K07 金健米业](K线与操作对照.md#k07) | 8/28—31为视频补充；9/3—4可对照C03 | 两笔不同理由的参与自述 | 压异动与消息低吸分笔；前者缺课程内完整规则，不能并入C05尾盘成交结构。 |
| [K08 国芳集团](K线与操作对照.md#k08) | C03局部对应；执行层 | 参与自述、日内及次日路径 | 可比较跟随与隔夜风险；9/21补述上周分三笔退出，确切日期、价格未知。 |
| [K09 沐曦](K线与操作对照.md#k09) | C04 | 提前关注、明确未买、事后改进 | 能核对事件后价格反应和未参与原因；全日涨幅不能写成账户收益。 |
| [K10 摩尔线程](K线与操作对照.md#k10) | C04；执行层 | 卖后接回仍失败自述 | 首次修复后继续走弱，原预期需重评；缺全部成交，不能重算亏损率。 |
| [K11 容大感光](K线与操作对照.md#k11) | C03局部转强；工具匹配与执行层 | 等转强参与自述 | 可讨论抢先低吸与转强的区别；不能当作C01大市值行业策略的完整证明。 |
| [K12 瑞尔特](K线与操作对照.md#k12) | C04的排除条件 | 周日事前明确不接、后续行情 | 高位一字结构与普通低位恐慌有别；未参与的跌幅不是实际避损金额。 |
| [K13 火炬电子](K线与操作对照.md#k13) | C03；执行层 | 补涨判断、走弱退出自述 | 核对队友强而候选不跟的失败；不能用后来的最高价替换真实卖价。 |
| [K15 白银LOF](K线与操作对照.md#k15) | 视频补充观察 | 价格反弹与自述 | 缺同步净值，尚不能检验溢价收益；不并入C06股债转换。 |
| [K16 新华医疗／新华都](K线与操作对照.md#k16) | C03；执行层 | 同名题材参与、退出及再次参与 | 核心封单与跟随溢价不同，监管及后排转弱需更新；不将同名公司都当作收购实质受益。第二笔9/21补述上周分三笔退出，确切日期、价格未知。 |
| [K17 源杰／云南／东山](K线与操作对照.md#k17) | 共同环境与执行层；C02压力思路的边界比较 | 压力观察、参与自述、反抽后再跌 | 科技群体不代替全体小票；不再跌停不等于趋势恢复，保留隔夜和再跌。 |
| [K18 星网宇达／国恩](K线与操作对照.md#k18) | C04；执行层 | 10/15低吸与10/16退出自述 | 两日链可回查，次日高开后路径分化；公告、每笔数量与精确成交仍待补。 |
| [K19 药明／权重ETF](K线与操作对照.md#k19) | C01局部对应；共同环境 | 市场观察，未见本人明确参与 | 股、行业与指数工具分开；放量不证明买入身份，比较ETF代码不冒充作者实际使用的基金。 |

## 三、后续怎样补证据

每个课程单元先写适用环境、选股或工具理由、参与与兑现条件、失败情形，再收录支持与反对的材料。材料字段保留：课号及时间点、课堂案例、B站日期及时间点、当时可见信息、行动类型、证券代码、完整价格路径、实际成交的已知与缺失、作者解释与研究推断。

当前优先缺口是C01完整容量交易链、C05尾盘订单与次日退出、C06同一时点股债及转换时间轴，以及各单元连续样本与失败退出。具体基建成果和完成标准合并在[总TODO第9、10项](../TODO.md)，本次只记录需求，不因重写总结自动建设或勾选。

73条视频与71天日记是资料池，已重点核对的41条按实际片段建立对应；其余不沿用旧视频标签自动转换课程分类。9/29及10/16补充了转债工具与保隆股债预期的观察，仍未确认本人买债，不能当作完整C06成交证据。机器索引见[整理索引](整理索引.json)。原来的视频模式目录和两份视频归纳报告已移出当前文档树，旧版可从Git提交`6789263`或本机忽略目录`课程视频/旧视频模式归纳_6789263/`回查。

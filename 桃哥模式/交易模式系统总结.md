# 桃哥交易模式系统总结：课程、公开视频与实际K线

[研究首页](README.md) · [逐案K线对照](K线与操作对照.md) · [证据与来源](课程实盘对照来源.md) · [课程总框架](../课程笔记/111-127_课程框架与B站研究衔接.md)

**目前最有依据的概括是：先判断哪一类股票具备修复或持续参与的条件，再选择有资金回流理由的方向与标的，用价格、承接和持有周期表达判断，最后随阶段变化调整仓位。** 急跌低吸是常见进场动作；指数修复、事件交易、特殊条件交易的驱动和退出安排各不相同。

本文将第111—127课与原有60条B站视频研究对照，本轮重新归档、抽样核对28条重点视频，补充39个股票、ETF及指数的连续不复权日线，形成17张案例图。研究的公开视频范围仍为2026年7月1日至9月18日，没有假定覆盖全年。操作是作者自述，K线用于核对价格路径；讲师观点、实际执行与本次归纳分别说明。

## 一、先分清环境、机会与动作

原目录的12类内容处在不同层次。研究时保留原目录，比较模式时按下表区分，避免把相互重叠的动作合算成同一套交易的胜率。

| 层次 | 内容 | 决定什么 |
|---|---|---|
| 环境与风险预算 | 历史类比、月份、位置、成交、压力源及强弱扩散 | 参与范围、持有周期、总仓位和是否少做 |
| 机会与标的选择 | 小盘整体修复、局部主线、核心个股、消息与已知事件、容量方向 | 为什么参与这一类机会，为什么选这个工具或股票 |
| 进场与兑现 | 急跌低吸、反核、转强跟随、竞价或冲高退出 | 成本、承接、日内与隔夜暴露 |
| 特殊机制 | 压异动、LOF溢价、尾盘成交结构、股债转换、新股定价 | 独立的条件、成交约束与失败路径 |
| 执行调整 | 底仓做T、加减仓、放弃或暂停 | 原有风险怎样变化，交易损耗怎样产生 |

例如，金健米业8/28属于尾盘特殊条件交易，9/3则被作者解释为农业消息后的低吸；同一股票也应按两次机会分别研究。指数修复底仓上的做T，与次日竞价离场的个股反核，同样不能混为一种持有安排。

## 二、他的上层判断怎样落到实际操作

### 1. 先确定在判断谁的环境

[111、112课](../课程笔记/111_大市值策略线.md)区分行业与市值风格，[113—115课](../课程笔记/113_平均股价＝2000.md)区分普通股票整体表现、少数涨停端和局部核心。[127课](../课程笔记/127_标的方向与容量选择.md)再将成长、红利、政策受益容量及小盘分开。

B站中能看到这种区别：[8/6约01:48—02:04](https://www.bilibili.com/video/BV1Ydu76cEw5/?t=108)强调小盘修复不等于大科技全部收回跌幅；[9/14约00:14—00:34](https://www.bilibili.com/video/BV1jWYk6YE1m/?t=14)在缩量中偏向小细分，认为大市值方向难推动。**这不是只看指数红绿，而是在比较实际能被资金推动的股票群体。**

### 2. 历史与月份给背景，位置和压力决定当前如何解释

[117—121课](../课程笔记/117_一年第一阶段行情规律.md)提出按月份及阶段研究，但同时提醒月内路径可能跨月；[123课](../课程笔记/123_高低位极弱与压力判断.md)补充高低位与压力传导差异。

实际链条中，7/17在反弹之前已类比2024年初并关注德明利；7/20仍有买早和压力未稳的问题；7/21修复后选择持有指数仓；8/17又因起点、月份和上方压力不同，不照搬2022年的长修复。见[K04／K14](K线与操作对照.md#k04)。

**本次归纳：** 历史类比是他的情景框架，盘面变化用于决定是否延续或调整；它尚不是经过完整样本验证的日历交易公式。

### 3. 仓位收缩有明确自述，执行仍会出现偏差

8/20明确因临近9月空间预期而减掉前日新增指数仓；9/3在缩量中自述两至三成仓位。[126课](../课程笔记/126_环境适应与回撤心态.md)把环境适应与保护成果联系起来。

但“理解风险”并不等于每次都按计划执行：兆易接回后再加、宇树首日参与亏损、康泰隔夜浮盈转亏、摩尔卖后又接，均在材料中出现。**评价他的模式，应同时解释赚钱机会和这些偏差，不能将实际执行理想化。**

## 三、模式一：小盘极弱后的ETF修复

**赚什么：** 参与普通小盘由集中抛售转向整体修复的一段共同上涨，而非押某个题材单独兑现。

| 要素 | 课程与操作能支持的认识 |
|---|---|
| 适用环境 | 前期普跌、价格空间已释放，关键压力对象出现承接变化，修复向普通小票扩散；需区别于弱市里孤立一天反抽。 |
| 选工具 | 以小盘指数相关ETF表达整体判断。7/21画面确认563300；不能用另一只2000ETF的价格代替。 |
| 买入观察 | 压力打开及承接、整体修复与扩散。7/17已有预期，7/20却仍买早，说明提前预判与确认解除有差别。没有统一“第几天、跌多少必买”规则。 |
| 持有与卖出 | 可保留底仓做阶段持有；8/7提出看首阴后反包和走弱，8/14下调空间，8/17—20进一步以阶段及月份解释减仓。 |
| 失败或需重评 | 压力继续、新风险叠加、指数改善但所持群体未改善、反弹未扩散，或上涨后反包不足、阶段转弱。后几项与作者退出观察对应，不能合成一个未经给出的固定价位止损。 |

**K线证据：** 德明利7/20仍收低位，7/21放量打开并修复；563300当日低1.181、收1.296，与约1.18买入及收盘1.296的自述、画面方向一致。但7/30收1.235，较7/21收盘回落4.71%，7/31后才进入后来那段连续阳线，不能写成一路上涨。8/13首阴后，8/14虽收阳但未回到前日开盘及高点区域。详见[K04／K14](K线与操作对照.md#k04)。

**最容易误学的地方：** 把“极弱后有修复”变成压力未解时不断加仓；把一笔低成本底仓成功，推广成每次指数回落都值得买。

## 四、模式二：有回流理由的核心股急跌低吸与反核

**赚什么：** 大环境或板块尚有参与条件，个股短时急跌后获得承接与资金回流的修复。普通急跌、连续杀跌和低位事件冲击需要进一步分组。

| 要素 | 课程与操作能支持的认识 |
|---|---|
| 适用环境 | 小盘整体改善，或局部主线、队友仍强；市场没有稳定普涨时，更依赖独立驱动和核心地位。 |
| 选股逻辑 | 先看方向和当前预期，再比较辨识度、同题材地位、已有跌幅与实际承接。熟悉、便宜、曾经很强都不足以单独入选。 |
| 买点类型 | 竞价恐慌、盘中急杀、跌停附近或打开后的反核，具体案例不同。他既会在下跌中提前买，也会转强后参与；没有统一百分比买点。 |
| 卖点与持有 | 常见为次日竞价、冲高分批退出，或卖原有仓位后决定是否接回；修复个股通常比指数底仓持有更短。实际也有卖早、未及时卖和回补失误。 |
| 失败或需重评 | 队友与核心转弱、预期已兑现、反弹承接差、同方向明显落后、隔夜没有预期溢价，或高位一字结构与普通恐慌不同。前几项主要是课程与反例提炼的检验边界；个股统一止损尚缺证据。 |

**对照例子：**

- [K05创业黑马](K线与操作对照.md#k05)：作者将小盘走强和传智当时强势作为依据。创业黑马8/5收盘仍跌2.98%，但从开盘修复11.55%，说明环境、买点与当日红绿需要分开。
- [K03上海港湾与巨力](K线与操作对照.md#k03)：同题材同日，前者收盘留下更多反弹，后者长上影、次日仍弱，支持选股不能只看标签。
- [K02兆易](K线与操作对照.md#k02)：接回后加仓仍下跌，反映成本管理不能代替选股与环境判断。
- [K12瑞尔特](K线与操作对照.md#k12)：周日明确排除高位一字类结构，次日实际高开后大幅下杀，是主动放弃的证据。

**最容易误学的地方：** 只复制“跌得够狠就买”，忽略为什么会被重新买回，以及什么情形是作者自己不愿接的。

## 五、模式三：消息、预期与题材短期反应

**赚什么：** 新信息带来的短期关注、板块扩散和个股重估。提前埋伏、消息首日跟随和分歧低吸是不同买点，不能事后统一成“早就知道”。

| 要素 | 课程与操作能支持的认识 |
|---|---|
| 适用环境 | 市场愿意响应题材，核心与队友能提供承接；弱环境中可以是局部机会，但并不消除共同风险和隔夜风险。 |
| 选股逻辑 | 消息关联、辨识度、当前预期、所处位置与同题材强弱。9/3金健包含农业辨识度及回落；9/15又反思弱标的不如上海洗霸、金龙羽等辨识度高的对象。 |
| 买点 | 首日消息出现后跟随或回落低吸，也有预期前埋伏。9/16光刻胶ETF未成交后转强追容大，体现工具与买点会改变。 |
| 卖点 | 偏短期兑现；8/20明确区分首日机会与次日高开后的参与。需跟踪次日自述，不能以当日分享卡结束复盘。 |
| 失败或需重评 | 消息已被价格反映、预期兑现、外部消息反转、次日板块低开、首日强势不能延续、买到后排或追价过高。 |

**K线证据：** [K06康泰](K线与操作对照.md#k06)8/20涨近20%，8/21却较前收低开8.78%；作者的浮盈转亏自述与方向一致。[K11容大](K线与操作对照.md#k11)当天涨6.74%、次日收跌1.36%，说明转强参与也要看具体成本与退出，不能假定凡追都赚或凡追都亏。

**最容易误学的地方：** 把消息首日强势当成可以无条件持有的基本面结论，或把消息关联最弱、位置最高的后排与核心等同。

## 六、模式四：已知利空落地、解禁后的承接修复

**赚什么：** 在风险已被提前交易的前提下，观察事件落地时新增卖压与实际承接是否不同于市场原先担心。解禁本身不是利好。

| 要素 | 课程与操作能支持的认识 |
|---|---|
| 适用环境 | 事件与日期提前可知，价格已有较充分调整，落地时出现承接；必须与经营继续恶化或突发新增风险分开。 |
| 选股逻辑 | 有明确事件、此前价格路径、可观察流动性与关注度；核对公告、可售数量和交易条件，不能只看“解禁”标签。 |
| 买点 | 作者在沐曦反思中提出，看开盘数分钟的成交与价格是否继续下压，而非只等更深跌幅。此为事后提出的改进，不能写成早已验证的标准流程。 |
| 卖点 | 摩尔有隔日竞价卖出及再接回的自述；没有足够材料给出这一类统一的持有期和退出价。 |
| 失败或需重评 | 卖压持续、初次反抽无延续、接回后再弱、新利空出现，或原以为已消化的风险仍在扩散。 |

**一正一反必须并列：** [K09沐曦](K线与操作对照.md#k09)放量修复，作者却明确未买；[K10摩尔](K线与操作对照.md#k10)卖后接回仍弱，并在之后继续下跌。前者证明存在某种市场路径，不能算他的盈利；后者说明不能由“已知利空落地”推出必然修复。

## 七、方向轮动与容量选择：决定把上述判断用在哪里

这是选机会和工具的一层，当前证据不足以把它写成单独、固定的买卖策略。

[111、112、127课](../课程笔记/127_标的方向与容量选择.md)要求区分小盘、成长、红利、金融及宽窄容量。原B站7/1—2记录中有科技、创新药、传统方向比较，也有证券未对冲科技的反例；本轮重点复核9/14缩量偏小细分、9/15核心与弱标的比较、9/16从ETF未成交转为个股转强参与。

**适用判断：** 先问机会广泛还是集中，成交能支撑多大范围，再比较宽基、行业、核心。方向和工具要对应收益理由。

**失败条件：** 假定备选板块天然与原方向相反；看对小盘却持大票；看对行业却选弱后排；把课堂的政策容量案例当作这批B站中已实际执行的完整交易。课程中的容量选择有清晰思路，但本批公开视频尚不足以验证每一种政策、红利与成长切换。

## 八、特殊机制单列，按证据多少控制结论

| 类型 | 适用条件与对象 | 买卖与兑现思路 | 主要失败条件与现有证据 |
|---|---|---|---|
| [压异动](07_压异动/手法总结.md) | 作者关注的连板背景、收盘条件、同类赚钱效应与参与氛围 | 围绕尾盘条件和次日兑现；金健8/28→8/31有跨日自述 | 竞价末端变化、软件口径分歧、无法成交、公告或停牌、情绪转弱。数值未触发不等于免于停牌；K07日线收涨也不能证明卖得好。 |
| [白银LOF](08_白银LOF溢价交易/手法总结.md) | 场内价格相对净值或参考价值的偏离，兼顾底层商品 | 作者自述溢价压缩后低吸反弹、短期兑现 | 净值滞后、商品变化、溢价继续收缩、退出受限。K15只有价格线，尚缺同步净值，不能验证价差收益。 |
| [转债日内](10_可转债日内交易/手法总结.md) | 股债与板块的联动、日内波动及可兑现性 | 7/2原归档属于工具讨论；122课区分日内跟随与隔夜预期 | 队友及正股次日不及预期、债股不同步、流动性不足。缺这批B站完整具体转债成交链，不能写成成熟实盘规则。 |
| 尾盘结构 | 122课提出的特定成交时点、剩余卖压、事件与公告条件 | 课程讨论尾盘打开后次日反应，需记录成交及可卖量 | 回封、未成交、公告和持续卖压。当前是课程案例，8/5 B站有尾盘ST操作线索，但未完成独立订单与状态核验，不据此认定“无视指数必赚”。 |
| 股债转换 | 125课岭南案例的相对价格、转股与事件条件 | 同步看债股价差、转换到账和实际可卖时间 | 正股继续跌、价差扩大、信用与退出约束。本批B站没有与该课配对的完整独立转换交易，暂列课程机制。 |
| [新股首日](11_新股首日博弈/手法总结.md) | 高定价、急跌后的价格与承接比较 | 长鑫等待而未买；宇树有亏损及再买修复自述 | 估值溢价、无承接、违背原计划后加大风险。属于尝试与反思，不能由标题涨幅统计为稳定模式收益。 |

## 九、做T与仓位：怎样保留或损耗已经得到的修复

[底仓做T](09_底仓做T/手法总结.md)叠加在原有观点和持仓上，不独立产生选股理由。原仓卖出、接回、额外加仓与取消接回要分别记录。

兆易7/6说明接回并加仓可能损掉先前优势；指数8/3原有记录显示卖后没有接回，8/12又有追回，说明做T也会卖飞；摩尔9/9则卖后接回仍跌。**这些行为共同说明：降低屏幕显示成本不等于提高整段净收益。**

仓位方面有减新增、保留底仓和两至三成的具体自述，但缺完整持仓数量、全部现金与每笔资金风险预算，不能据此构造固定全年仓位表。课程中“先保住资金和成果”的方向较清楚，实际执行的一致性仍需逐笔证据。

## 十、买卖点和失败条件，应怎样使用这份总结

最可靠的做法是分成三档：

| 证据档次 | 当前内容 | 可以得出的结论 |
|---|---|---|
| 作者明说并有操作或计划线索 | 指数首阴后看反包、阶段减仓；瑞尔特事前不接；消息偏首日；摩尔卖后接回；沐曦明确没买 | 可以描述作者的判断、计划、行为及改进，按时间顺序核对。 |
| 课程与反例提炼的边界 | 队友转弱、预期兑现、承接消失、买点过高、隔夜反转、工具错配 | 可以作为模式是否仍成立的检查项；不能宣称他每次都据此止损。 |
| 当前缺失 | 个股统一止损幅度、每笔风险预算、补仓上限、全部持仓与完整成交、各模式全样本收益 | 明确留空，不补成机械交易系统，不据精选案例计算账户胜率。 |

一个可复用的案例描述顺序是：**当时环境 → 当前机会与预期 → 为什么选它及备选 → 实际触发与成本 → 隔夜和后续 → 退出或调整 → 失败与未做的对照**。这套结构已用于[逐案K线对照](K线与操作对照.md)，研究基建需求继续归入[总TODO第4—10项](../TODO.md)。

本轮最明确的认识是：他的操作包含环境择时、方向与核心选择、价格和承接判断、持有节奏及仓位管理；执行中也会出现追入、买早、补仓、未兑现和踏空。现有证据足以解释这些决策类型与边界，尚不足以证明一个统一参数、稳定胜率或无条件套利模型。

# 第一项研究：一字跌停后的首日开板确认

方案日期：2026-10-23。建议先完成这一个窄分支的可靠回放。它已有程序、11段课程案例及通达信交叉核查，较容易明确候选、触发与退出时序；竞价末秒指示价、历史封单和自由裁量的核心判断尚缺完整资料，先作为解释字段。其他分支继续保留，暂不共同调参。

## 这轮回答一个问题

普通主板情绪连板股票连续一字跌停后，在首日开板出现完整5分钟收盘确认时参与，下一交易日早盘退出，能否在可解释的成本及成交约束下得到稳定的正收益？

这是研究者对课程的可执行代理，不能直接称桃哥原样买卖。既有2024命名案例是发现与程序核查材料；本地另一次9/8—10的9股票日、5触发、均值净收益-5.16%的试验采用“昨跌停、开盘再跌、回升”规则，是另一项失败发现试验，必须保留，不能合入本项或通过新命名抹除。

## 先冻结一个主版本 LD-OPEN-01

| 环节 | 主版本约定 |
|---|---|
| 市场范围 | 普通沪深主板10%涨跌幅制度；使用历史ST、停牌、上市状态与公司行动，无法核对的列资格未知，不自动放行 |
| 事前候选 | 昨日OHLC全部等于当日跌停价，至少连续1个交易日；此前15个交易日内最大连续收盘涨停数至少3日，沿用既有研究的情绪连板价格代理 |
| 原代理的漏选 | 神驰等不满足3连板代理的课程命名案例独立保留；本轮不为覆盖作者而临时放宽 |
| 研究事件 | 一段连续一字之后的首次开板日；连续一字的每个观察日仍在底表，不能只记录最终打开的赢家 |
| 入场信号 | 首根完整5分钟收盘价高于当日跌停价，最晚14:30确认；竞价打开也等该根完成 |
| 入场价格 | 信号完成后下一根5分钟开盘作模拟参考；该根缺失、无量、单一价、开盘处于涨跌停或其他既有执行检查失败，记入场未确认，本事件不再追选后续最好点 |
| 仓位路径 | 每事件只初始买入一次，次日退出；本轮不加仓、不做T、不重复抄同一事件 |
| T+1退出 | 次日09:30开盘作主参考；受跌停、无量等约束不能确认退出时，沿用程序逐根延后并记录全部延后原因；整日无法退出则保留仓位与浮动结果，不删除 |
| 成本 | 按毛收益减双边总成本0.30个百分点为基础情景，0.60个百分点为压力情景；另核验对应时期最低佣金、印花税和实际冲击，不称固定值为实际收费 |
| 容量 | 固定1万元为研究示例；整根成交额1%检查仅为事后容量诊断，不冒称开盘已知，也不证明开盘可成交 |
| 其他特征 | 相对竞价金额、历史换手、队友、风险事件、前排依据先存原值与来源；本主版本不依据已看结果增删门槛 |

主版本选用既有A入场、X1退出的基本结构；旧B与X2/X3等所有已试组合继续登记为探索试验。主版本提出于旧结果已知之后，不能把旧11例再称为它的样本外证据。未来改动须新编号和新的验证段。

## 三份依次验收的成果

### 1. 先把数据闭环做完

先复用现有14只课程股票、11段序列，逐日输出日线、分钟汇总与交易日历的差异清单，定位到入场与退出需要的那根价格。通达信240个分时点只有采样价格，不提供完整分钟OHLC，不能代填分钟最低。存在争议只暂停受影响事件的收益统计，同时报告排除比例及方向，避免剩余样本选择性变好。

交付：数据覆盖清单、争议修复记录和11段逐根时间表。能从原始数据重算每项信号与参考执行；缺资料的明确到供应商、日期、字段。优先解决分钟价格和交易资格，历史封单不是本主版本的先决字段。

### 2. 按冻结规则扩展到完整候选

计划窗口：2023-01-01—2024-12-31用于开发与数据检查；2025-01-01—2025-12-31预留作历史验证。运行前核查项目以往是否已经用2025结果改过同类规则；若用过，就降为发现材料，另冻结未用于开发的新日期。2026已观看视频样本只作动作对照，不自动称未见样本。

完整扫描窗口内全部历史合格股票，包含退市对象与无触发日。若只拿到课程命名名单，交付应明确是名单回放，不能宣称全市场验证。各阶段保存候选总数、数据缺失、持续封死、触发、放弃、成交未确认及退出受阻，不能只展示成交样本。

交付：逐事件明细、基础及压力成本结果、逐月分布、持有期间最大不利波动、最差个案、跌停退出受阻天数。先报告等权事件收益及交易日聚类的不确定性；组合年化、夏普和资金回撤待仓位占用与并发规则另行冻结后计算。

### 3. 独立日期连续模拟

冻结版本后，从下一个实际完成数据接入的交易日开始，连续记录至少20个交易日，连同零候选日一起保存。若事件很少则延长，不为凑交易改条件。原程序输出、实际可见时间和模拟成交状态同时归档；现有监控是否部署不等于本研究已经开始前向记录。

第一份历史结果目标至少100个合格事件、验证段至少30个事件；这只是初步覆盖目标，达到数量不代表统计充分。样本较少时报告“证据不足”，不凑成高胜率。

## 怎样判定结果值得继续

- 验证段基础成本下均值为正，压力成本下不明显反转；检查按交易日聚类的区间，区间仍跨零则不能确认优势。
- 收益分布、最差事件和退出受阻可解释；正收益不能只由一两笔或单一行情月份贡献。
- 同一冻结版本在不同阶段能重现，数据缺失与未退出样本全部披露，不能靠删除它们改善结果。
- 未通过时保存失败版本，再决定有机制依据的下一项试验。先核查数据、入场成本、隔夜跳空和退出损耗，不同时搜索一批金额、跌幅、时长参数。

本轮用户下一步最有价值的投入，是提供公开视频中能事前认定“核心／后排、为什么不买”的对照解释，供后续独立筛选研究。数据抓取、复算和程序核查由研究流程完成；暂时不用继续寻找作者未展示的精确成交图，也不必先接QMT。

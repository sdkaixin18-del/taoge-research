# 观察标的与交易标的的反抽量化

**先确认压力缓和，再确认篮子和交易工具响应，最后比较剩余收益与失败代价。** 输入观察标的和实际交易标的，可以形成一张包含参与条件、价格上限、目标、失败边界及退出时间的观察卡。数据不足、关系未验证和空间不足都应留下结果。

本页是由课程思路延伸的研究规则，版本0.1，2026年10月17日整理。课程没有给出下文的ATR阈值、收益风险比或KSTR交易系统；这些参数尚未通过独立样本验证。

## 下次怎样输入

可以直接在对话中发送：

> 观察标的：源杰科技688498；交易标的：Binance KSTRUSDT永续；分析时点：现在；持仓：无。

时间省略时按查询当时处理，并标注最后一根完整K线的时间。历史复盘需补日期和时点。已有持仓时补充实际买入时间、均价、预先确定的止损与目标，才能区分“还能不能新开”和“已有仓位怎样处理”。往返成本未知时，分别展示假设情景，不把未知费用填为零。

观察卡固定回答：

| 问题 | 输出 |
|---|---|
| 两个标的是否适合配对 | 产品身份、经济关联、篮子代表性、同步与滞后收益相关、样本范围 |
| 压力是否缓和 | 观察标的的压力低点、修复幅度、近期是否再创新低 |
| 修复是否传导 | 篮子响应数量、交易标的是否跟随，区分试错与确认 |
| 当前价格是否值得参与 | 参考价、第一和第二目标、失败边界、净收益风险比与最高参考参与价 |
| 何时退出 | 目标触及、固定边界破坏、修复迟迟不来、约定时间到达 |
| 什么仍不能判断 | 过期或缺失行情、配对未验证、成本未知、实际成交与触发方式缺失 |

新配对先由研究流程核对身份与篮子，程序目前不自动读取持仓和事件公告。“都是科技”不足以建立联动。现有公开行情适配器覆盖A股观察对象和Binance USDT永续交易对象；其他市场可导入相同格式的行情，但需另接数据源。

## 三层观察与初始规则

| 层次 | 当前研究定义 | 源杰到KSTR的例子 |
|---|---|---|
| 压力对象，5分钟 | 截至当时的日内高点到最近12根低点的跌幅至少2%；从该低点修复至少0.5个ATR；最近3根的低点均高于压力低点加0.1个ATR | 源杰缓和意味着观察到的卖压状态改善，不能直接代替KSTR买点 |
| 传导篮子，15分钟 | 收盘高于上一根，且本根低点不低于此前日内低点；逐个记录 | 科创50ETF588000与寒武纪688256。两者均通过为确认；只有部分通过为试错 |
| 交易工具，15分钟 | 收盘回升，本根低点不低于此前3根最低点，再检查目标与风险 | KSTR必须自己响应；源杰反弹而KSTR继续弱则继续观察 |

ATR取已完成K线的真实波幅简单平均，最多14根。压力与篮子只使用A股有效交易时段；KSTR午休期间仍有真实交易，但不能把A股冻结报价当作新确认。初版要求当日观察与交易序列各至少6根完整K线，因此15分钟执行序列在11点前处于预热阶段，未覆盖开盘抢反弹。

所有计算统一到北京时间的K线完成时刻，未完成K线不参与。源杰的5分钟信号与篮子、交易工具的15分钟确认频率分别保留。分钟缺口、过期数据及14:55以后都暂停新增候选；节假日或停牌没有当日行情时也会暂停。

## 买点必须同时满足价格条件

初版将交易工具最近两根完整K线的最低价减去0.1个ATR，作为研究用失败边界。第一目标取当前价上方最近的、已经有右侧完整K线确认的局部高点，开盘价也作为已知参考位；其后的价位列为第二目标。目标缺失时不形成价格方案。这个机械取法仍需与更长周期的压力区域比较，不能为提高收益风险比跳过第一处压力。

以参考入场价E、第一目标T、失败边界S、往返成本占名义金额比例c计算：

```
净目标空间 = T / E - 1 - c
失败代价   = 1 - S / E + c
净收益风险比 = 净目标空间 / 失败代价
```

初始研究门槛设为1.5，对应最高参考参与价：

```
最高参考参与价 = (T + 1.5 × S) / [2.5 × (1 + c)]
```

这样能具体回答“信号成立，但已经追贵了没有”。参考价来自最后一根完整K线，实际成交价格、价差或成本变化后须重算；输出并未按合约最小价格单位生成可直接提交的订单。

已有仓位的止损与目标沿用入场记录，不因后来的新低向下修改。第一、第二目标用于核查分批兑现，比例需事前确定。另记录两类退出条件：入场后3根完整15分钟K线仍未修复0.5个入场ATR，以及约定当日退出时间到达（示例14:55）。观察对象跌破入场时固定的压力低点，也记录原判断失败。若只是某只观察股转弱而篮子仍强，应复核其代表性，不能推断整个科技方向都要跌。

当前工具回顾的是成交价K线与目标触及，不是券商或交易所的实时止损系统。标记价止损需要对应标记价数据，程序遇到该输入会拒绝用成交价代算。同根同时触及止损和目标时不判断先后；入场所在K线的入场前高低点也不算持仓表现。实际退出是否成交须另存记录。

## 配对诊断与接下来的验证

使用公开接口取得、截断至2026年10月9日11:30的历史数据，计算9月11日至该时点的15个交易日：共同完整区间203个；排除跨午休、隔夜和缺口的收益，不以前向填充制造股票连续交易。将源杰区间收益与随后一根KSTR区间收益配对时为174组。

| 观察对象 | 与KSTR同步收益相关 | 与随后一根15分钟KSTR收益相关 |
|---|---:|---:|
| 源杰科技 | 0.395 | 0.164 |
| 科创50ETF588000 | 0.754 | 0.328 |
| 寒武纪688256 | 0.581 | 0.249 |

这组样本支持优先把篮子作为传导核对，不能据此断定哪个对象稳定领先。相关不是胜率，也不等于控制市场因素后仍有额外预测力。分钟资料是事后下载的历史版本；按时点截断能够防止直接使用未来价格，不能证明历史数据从未修订。

当前配对状态始终标为“未验证”。20个交易日只是初步样本覆盖检查，达到也不会自动升级为有效策略。后续应冻结规则，连续纳入所有符合和不符合的时段；按交易日划分研究与独立检验区间，保留失败、未成交和主动放弃。比较“只看篮子”“只看KSTR”与“加入压力对象”后的成本收益，才知道源杰是否提供额外价值。

策略评价至少报告样本数、入场后最大不利波动、胜率、平均盈利/亏损、净期望、最大回撤、持有时长，以及成本提高后的表现。净期望按“胜率×平均盈利－败率×平均亏损－成本”计算，若盈亏已经扣成本则不重复扣除。缺少止损或目标的成交先后、价格保护与真实费用时不生成精确收益结论。关联[TODO第7、9、10项](../TODO.md)。

## 本地原型使用

源码、测试及运行说明已整理到[量化程序](../量化程序/README.md)，随Git保存；原始行情、缓存及回放结果继续保存在Git忽略的[本地素材目录](../课程视频/跨标的反抽工具/)。运行需要Python 3.9以上，无第三方包；读取公开行情，不连接交易账户。以下命令在仓库根目录执行，需要本机已有案例行情。

```sh
python3 量化程序/quant_watch.py --observe sh688498 --trade KSTRUSDT --as-of 2026-10-09T11:30:00+08:00 --offline-case 课程视频/KSTR对照_20261017 --cost-bps 15
```

去掉`--offline-case`会读取腾讯财经与Binance公开行情，并将原始返回、请求、获取时间和SHA256保存在`课程视频/跨标的反抽工具/行情缓存/`；去掉`--as-of`使用当前时间。KSTR示例默认篮子为588000与688256，其他配对需指定`--basket`，不能猜测。公开接口的分钟历史有限，历史时点缺失会暂停，不用今天的报价替代。

用`--data`可输入[标准行情样例](../课程视频/跨标的反抽工具/标准行情样例.json)相同结构的数据，身份代码必须匹配。用`--position`输入JSON，字段包括`entry_time`、`entry_price`、`stop`、`targets`，以及可选`source_low`、`entry_atr`、`exit_by`；当前`stop_basis`仅支持`last_price`。用`--out`保存JSON观察卡。时点均须带时区。

验证覆盖所有回放时点的未来数据截断一致性、修改未来价格不改变过去结果、午休、数据缺口、输入身份、成本、最高参与价公式及持仓触发口径；公开接口也已与离线案例对照。检验脚本为[历史案例测试](../量化程序/test_quant_watch.py)，缺少本地案例行情时明确跳过。这些是程序正确性检查，未验证策略盈利能力。

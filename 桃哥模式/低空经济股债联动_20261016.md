# 低空经济的板块强度与股债滞后案例

**本例的核心是：正股抢先封板，板块随后扩散，增强了它作为事件核心、次日可能一字的预期，转债在当天交易这份预期的上修。** 桃哥在视频中明确用这条逻辑解释保隆债拉升。债先横盘后加速是价格表现，正股早封的地位与次日预期变化才是这类机会的选择依据；午后正股仍封板而债回落，保留退出边界。

课程归属放在[C03主线核心与当前预期](交易模式系统总结.md#c03)及[C06股债联动](交易模式系统总结.md#c06)，不另建按视频名称划分的模式目录。这里的“强度套利”是依赖资金继续传递的方向性跟随交易，没有锁定价差收益。整理日期2026年10月18日。

**同日扩展筛选已补齐：** [24股、7组有效股债及价格路径](低空候选筛选_20261016.md)。声迅与广泰属于低空相关股债观察，但正股当天均未涨停，不满足本例“早封核心、次日一字预期”的完整前提。广泰在宽泛价格规则下未获利的记录保留，作为缺少核心地位过滤的对照，不冒充同模式失败。航空、材料外围及已停止交易的旧债另列。

## 早封时间怎样变成次日预期

**保隆先封板时，能看到的是它抢先响应事件；同方向股票继续走强后，早封的意义进一步变为“可能被当作板块核心，次日更难买到”。** 因而，正股封板与债加速之间的一段时间，不必全部解释为资金发现得晚；板块扩散本身提供了新的定价信息。这是依照桃哥00:30—00:40解释作的机制归纳，不能由价格精确识别每笔资金的想法。

| 当时的观察顺序 | 已经形成的依据 | 对转债判断的作用 |
|---|---|---|
| 保隆09:31一分钟线已收涨停 | 在所核对的核心篮子中抢先上板 | 可以列为事件核心候选，此刻还不能把随后全板块走强当成已知。 |
| 万丰09:45一分钟线收涨停；其他队友上涨 | 同方向获得更多价格确认 | 保隆早封的相对地位得到助攻，次日被抢筹的预期有了更强依据。 |
| 10:00—10:30队友保持强势，保隆债仍整理 | 核心保持领先，板块支持仍在；债尚未明显加速 | 研究“次日预期是否上修、债是否已反映”，而非只比较股债涨幅差。 |
| 10:35债自身突破整理 | 预期判断又得到债价格和成交的确认 | 可作为确认执行分支；突破参数本身不构成模式的选股理由。 |
| 金盾10:57、宗申11:10、中信11:17、上工11:19一分钟线先后收涨停 | 午前扩散进一步增强 | 这些是后来新增的信息，不能倒填为10:35参与的全部理由。 |

上表为供应商分钟标签，不是逐笔首封时刻。金盾首次分钟触及涨停在10:52，首次分钟收涨停在10:57，两者也不混用。保隆截至10:35，自09:31首次分钟收涨停后，后续一分钟线最低价未观察到跌离涨停；这支持该尺度下的稳定性，不能重建封单、撤单和逐笔开板次数。明细见[本地时间核对](../课程视频/低空股债联动_20261016/扩展筛选/早封与板块扩散时间核对.json)。

正股当天已在涨停价，无法继续通过当天股价上涨完整表达更高的次日预期；转债可以继续交易未来正股情景。正股当前转股价值不变、债溢价上升，与这条逻辑相容。溢价和债性用于检查买入成本、弹性及预期是否已经透支，不能取代对早封地位和次日预期的判断。

## 选上工与选转债是两条执行分支

**股票分支是板块内跟随。** 上工与万丰、金盾、宗申等放在同一观察方向后，还要比较当时主动性、承接和买价。上工09:45收8.50，10:30收8.22，期间变化约−3.29%，之后才在11:20标签的5分钟线收至8.94。最终封板不能反过来证明早盘任何买点都好；作者具体买点未披露，普通股票隔夜风险也没有因当天补涨消失。

**转债分支优先核对自身正股。** 保隆科技603197与保隆转债113692的发行人对应关系可由[上交所上市公告](https://www.sse.com.cn/disclosure/announcement/listing/stock/c/c_20241122_10764887.shtml)核实。正股早封板、同方向股票强、债尚在整理，形成了比“同属科技就会跟”更直接的观察链；债价仍会受溢价、债性、流动性及短线预期影响，不与正股涨幅等比例对应。

选择流程应是：先找板块已确认的强正股，核对它有没有当时仍可交易的转债，再检查债自身的位置、成交和失效位。只因为某债贴低空标签、涨幅小或者以前活跃，仍不足以入选。[扩展核查](低空候选筛选_20261016.md)已取得7组有效股债序列，保留题材层级、确认与未确认；先前空数组中的商络、胜蓝旧债、金钟已由公告证明当日前停止交易，胜蓝继任债也已经停止交易，不能算本日亏损样本。

保隆债10:30累计量已为前6日同期均量约4.01倍，并非一直无人关注；当时有效转股价38.78、转股价值75.786、债价123.186，对应溢价62.54%。低涨幅没有形成可锁定的转股价差。此前价格敏感度、存量规模及早盘债市较弱可以作为解释线索，不能据此断言具体资金故意迟到。同步计算、依据和范围见扩展报告。

## 可重复使用的观察与执行条件

以下为由课程延伸的研究模板，不是桃哥已经公布的机械系统。

| 环节 | 应检查的证据 |
|---|---|
| 适用环境 | 事件仍有当前预期，正股抢先封板后，同方向继续扩散和承接，增强其核心地位及次日更强的预期。 |
| 选择股票 | 有当前题材依据和辨识度，同时比较相对表现、回踩承接与可成交价格；过去熟悉只帮助发现对象。 |
| 选择转债 | 自身正股有较早封板及事件核心依据，并有板块助攻形成次日预期；再核对有效转债、债价已反映多少预期、成交深度及溢价。相关股只涨几个点不足以替代。 |
| 预判参与 | 早封核心的次日预期因板块扩散而上修，债尚未明显加速；写清预期依据、整理失效位及最长等待时间，承担债始终不跟的风险。 |
| 确认参与 | 等债自身突破已形成的整理区并出现成交响应，再按当时可买价格重新检查空间；不能把横盘低价当成确认后的成交价。 |
| 获利了结 | 次日预期已被债价快速上修反映时分批兑现；债自身转弱或重回整理区时处理剩余部分。赚的是当日预期重估，不必等次日真的一字。 |
| 判断失败 | 早封后反复开板、板块助攻退潮或核心地位被替代，削弱次日预期；债迟迟不跟或突破回落；债价已提前透支、独立失去承接，即使正股仍封板。 |

本例的预判观察窗口可放在10:00—10:30，债开始确认的研究时点在10:35附近。两个分支的成本和失败方式不同，后续应分别检验；不能把前者的低价与后者的确定性拼成一笔理想交易。缺乏历史盘口、实际挂单与完整成交，本次不造精确买卖点、最大可赚收益或胜率。

这次最值得保留的退出反例是：保隆正股几乎没有从涨停价回落，债却明显下跌。日内债的买盘和溢价变化，足以让“等正股开板再走”迟到。T+0提供当日退出的机制，也要求实际执行退出，而不是天然消除回撤。[上交所现行交易细则第五条及涨跌幅规定](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/trading/currency/c/c_20250606_10781040.shtml)确认当日回转及非首日20%涨跌幅；本例触及20%是涨停价，不能写成上市首日20%临停。

## 午后退出还要看市场环境

同步一分钟线显示，13:10上证较11:30收盘约−0.39%、中证转债约−0.18%，13:20分别约−0.54%、−0.46%；保隆债仍在145.159，正股仍封。13:30债才首次在本轮分钟线中打开涨停，收142.931。市场走弱早于债自身价格破坏，支持增加更早的环境风险及利润保护提示，不能只等正股开板或债跌破自身结构。

这为大盘及债市共同承压参与解释提供时间证据，不能单独证明因果贡献。具体同步图、新闻Agent前置发现、市场风险与股债持续状态的联合设计见[项目重整方案](转债监控_事件Agent与市场风险优化.md)。旧价格回放及延迟退出参考保留，未事后改成更早已卖出。

## 后续怎样固化

已进一步形成[早封核心转债的量化定义与监控优化](早封核心转债_量化定义与监控优化.md)：按当时分钟线核对排除自身后的助攻、早封稳定性、债的确认与参与价上限，并对照现有`cb-limitup-monitor`提出持续机会状态及债自身风险提醒的设计，尚未改动线上监控。

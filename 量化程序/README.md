# 跨标的反抽观察程序

输入观察标的、交易标的和分析时点，按“压力缓和→篮子响应→工具响应→成本与空间”生成观察卡，并核查已有持仓的固定止损、目标和退出时间。研究规则及案例见[跨标的反抽量化](../桃哥模式/跨标的反抽量化.md)。当前版本为`0.1-research`，未完成独立样本的盈利检验。

源码与测试随Git保存；历史行情、缓存、观察卡和图表继续放在Git忽略的[课程视频目录](../课程视频/)。本次整理沿用原型的规则与参数，仅调整源码、测试和默认缓存的存放路径。

## 运行

需要Python 3.9以上，使用标准库，无需安装第三方包。以下命令均在仓库根目录执行。

使用本机已有的10月9日案例：

```sh
python3 量化程序/quant_watch.py \
  --observe sh688498 --trade KSTRUSDT \
  --as-of 2026-10-09T11:30:00+08:00 \
  --offline-case 课程视频/KSTR对照_20261017 \
  --cost-bps 15 \
  --out 课程视频/跨标的反抽工具/运行结果/观察卡.json
```

`--offline-case`只适配这组源杰科技→KSTR本地案例。Git副本不附带案例行情，需另行准备本地数据。去掉该参数会读取腾讯财经与Binance公开分钟行情；去掉`--as-of`则使用当前时间。原始返回、请求、获取时间与SHA256默认存入`课程视频/跨标的反抽工具/行情缓存/`。

KSTR默认篮子为`sh588000 sh688256`；新配对须用`--basket`明确篮子。其他市场可用`--data 本地行情.json`导入标准结构，程序会核对`--observe`和`--trade`的身份：

| 字段 | 内容 |
|---|---|
| `observe`、`trade_symbol` | 观察对象与交易对象代码 |
| `source_fast` | 观察对象5分钟K线数组 |
| `source_slow` | 观察对象15分钟K线数组 |
| `basket` | 篮子代码到15分钟K线数组的映射 |
| `trade` | 交易对象15分钟K线数组 |

每根K线包含`end`、`open`、`high`、`low`、`close`；`end`为带时区的完成时间。数据结构样例仍在[本地样例文件](../课程视频/跨标的反抽工具/标准行情样例.json)。程序只使用分析时点之前已完成的K线；缺口、过期行情和A股午休会暂停新增候选。

`--cost-bps`输入往返总成本情景，1基点为名义金额的0.01%；未知成本不会按零处理。`--position 本地持仓.json`可核查固定的`entry_time`、`entry_price`、`stop`、`targets`，以及可选的`source_low`、`entry_atr`、`exit_by`。当前仅支持成交价触发口径`last_price`。程序读取公开行情，不连接账户或提交订单。

## 检查

```sh
python3 -m unittest discover -s 量化程序 -p 'test_*.py'
```

18项历史案例检查覆盖逐时点截断、未来价格扰动、午休、缺口、成本、参与价上限与固定持仓边界。本机有案例行情时执行全部检查；没有`课程视频/KSTR对照_20261017/source_signal_alignment.json`时明确跳过，不联网补行情。检查通过只说明这些程序行为符合预期。

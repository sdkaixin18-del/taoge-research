# 跨标的反抽观察程序

输入观察标的、交易标的和分析时点，按“压力缓和→篮子响应→工具响应→成本与空间”生成观察卡，并核查已有持仓的固定止损、目标和退出时间。研究规则及案例见[跨标的反抽量化](../桃哥模式/跨标的反抽量化.md)。当前版本为`0.1-research`，未完成独立样本的盈利检验。

源码与测试随Git保存；历史行情、缓存、观察卡和图表继续放在Git忽略的[课程视频目录](../课程视频/)。本次整理沿用原型的规则与参数，仅调整源码、测试和默认缓存的存放路径。

## 运行

需要Python 3.9以上，使用标准库，无需安装第三方包。以下命令均在仓库根目录执行。

使用本机已有的10月9日案例：

```sh
python3 量化程序/quant_watch.py \
  --observe sh688498 --trade KSTRUSDT \
  --as-of 2026-10-09T11:30:00+08:00 \
  --offline-case 课程视频/KSTR对照_20261017 \
  --cost-bps 15 \
  --out 课程视频/跨标的反抽工具/运行结果/观察卡.json
```

`--offline-case`只适配这组源杰科技→KSTR本地案例。Git副本不附带案例行情，需另行准备本地数据。去掉该参数会读取腾讯财经与Binance公开分钟行情；去掉`--as-of`则使用当前时间。原始返回、请求、获取时间与SHA256默认存入`课程视频/跨标的反抽工具/行情缓存/`。

KSTR默认篮子为`sh588000 sh688256`；新配对须用`--basket`明确篮子。其他市场可用`--data 本地行情.json`导入标准结构，程序会核对`--observe`和`--trade`的身份：

| 字段 | 内容 |
|---|---|
| `observe`、`trade_symbol` | 观察对象与交易对象代码 |
| `source_fast` | 观察对象5分钟K线数组 |
| `source_slow` | 观察对象15分钟K线数组 |
| `basket` | 篮子代码到15分钟K线数组的映射 |
| `trade` | 交易对象15分钟K线数组 |

每根K线包含`end`、`open`、`high`、`low`、`close`；`end`为带时区的完成时间。数据结构样例仍在[本地样例文件](../课程视频/跨标的反抽工具/标准行情样例.json)。程序只使用分析时点之前已完成的K线；缺口、过期行情和A股午休会暂停新增候选。

`--cost-bps`输入往返总成本情景，1基点为名义金额的0.01%；未知成本不会按零处理。`--position 本地持仓.json`可核查固定的`entry_time`、`entry_price`、`stop`、`targets`，以及可选的`source_low`、`entry_atr`、`exit_by`。当前仅支持成交价触发口径`last_price`。程序读取公开行情，不连接账户或提交订单。

## 检查

```sh
python3 -m unittest discover -s 量化程序 -p 'test_*.py'
```

18项历史案例检查覆盖逐时点截断、未来价格扰动、午休、缺口、成本、参与价上限与固定持仓边界。本机有案例行情时执行全部检查；没有`课程视频/KSTR对照_20261017/source_signal_alignment.json`时明确跳过，不联网补行情。检查通过只说明这些程序行为符合预期。

强势回调与超跌反抽的股票筛选另见[选股程序](../选股程序/README.md)。

## 情绪股一字跌停开板研究

[研究报告](../桃哥模式/情绪股一字跌停后的开板研究.md)将前一天的开板预判、开板日A/B参与与次日X1/X2/X3退出分别检验。[离线程序](limitdown_research.py)是独立研究脚本，不接账户或线上提醒，也不改变原反抽规则。

本轮扫描14只课程命名股票、2024年2月19日至5月10日，得到11段一字序列和18个观察日；此前15日最大连续收盘涨停至少3日的价格代理覆盖10段，神驰2连板作为漏选对照保留。封单历史缺失，全部11段存在日线与分钟量额争议，其中6段另有价格差异，故22个A/B参与代理及66个退出组合只保留争议情景，合格收益分母为零。程序检查通过不代表盈利能力已验证。

在仓库根目录运行，Python标准库即可：

```sh
python3 量化程序/limitdown_research.py \
  --study-dir 课程视频/情绪股一字跌停开板_20261018 \
  --out 课程视频/情绪股一字跌停开板_20261018/回放结果
python3 -m unittest discover -s 量化程序 -p 'test_limitdown_research.py'
```

`--study-dir`需要本地已有本轮封存协议、对应SHA256和`原始行情/`，Git不提供行情及公告。协议包含`universe`（市场代码到名称）、研究窗口等本轮设定，脚本核验协议哈希；A/B与X1/X2/X3的具体操作定义固定在源码与报告中，不是参数搜索工具。输出JSON另存源码及原始输入哈希。

`原始行情/市场代码_日线.json`与`市场代码_5分钟.json`顶层为`requested,retrieved_at,provider,rows`。`rows`保存BaoStock0.9.4原字段字符串；日线须有`date,code,open,high,low,close,preclose,volume,amount,adjustflag,turn,tradestatus,pctChg,isST`，分钟须有`date,time,code,open,high,low,close,volume,amount,adjustflag`。`time`为K线结束时刻，量为股、金额为元、`adjustflag=3`；另需`sz159628`同区间日线及分钟作为环境代理。当前脚本只适配报告中的普通主板10%制度，不直接套ST或其他板块。

本机重取数据的脚本在[本地研究目录](../课程视频/情绪股一字跌停开板_20261018/获取行情.py)，需要安装`baostock==0.9.4`，按顺序请求，已有缓存不覆盖；腾讯交叉请求及公告原文下载脚本也在该目录。异机使用时须另行准备同结构输入，不能仅靠Git副本复现行情。

输出包括逐日观察、完整序列、参与退出情景及行情核查四份CSV与完整JSON。封单字段保持空值，不能由日线成交额补造；次日开盘仍跌停时保留退出受阻。10项边界测试覆盖未来数据、午休、涨跌停执行和数据争议处理。

### 分钟与封单追加复核

[跨源复核程序](limitdown_data_audit.py)保持原协议及回放不变，读取公开通达信历史分时、分笔和封单证据。40日分时收盘全部与日线相同，量差最大49股；原A首次确认时点11/11一致，华生B的收盘抬高条件不成立。完整低点、执行与封单仍缺，程序不会将点价转换成完整OHLC或输出已验证策略收益。结论和原因见[研究第九节](../桃哥模式/情绪股一字跌停后的开板研究.md#九追加复核分钟差异封单来源与模式验证)。

```sh
python3 量化程序/limitdown_data_audit.py \
  --study-dir 课程视频/情绪股一字跌停开板_20261018 \
  --check-dir 课程视频/情绪股一字跌停开板_20261018/复核_分钟日线与封单 \
  --out 课程视频/情绪股一字跌停开板_20261018/复核_分钟日线与封单/复核结果
python3 -m unittest discover -s 量化程序 -p 'test_limitdown*.py'
```

追加输入保存在`--check-dir`：`通达信历史分时/市场代码_YYYY-MM-DD.json`含`symbol,date,provider,host,retrieved_at,rows`，每行仅`price,vol`，量按手×100；必须240点，缺点报错。`通达信历史分笔/`同名JSON保存原分页及按时间合并的`rows`，含`time,price,vol,buyorsell`，时间只有HH:MM。分时结束点时标与前一分钟最后一条采样分笔核对，15:00另作竞价点。价格点不提供区间高低价，分笔也不含卖一库存。

`历史封单证据.json`独立记录`kind,quantity,unit,relation,snapshot_time,available_at,prediction_cutoff,source_url`。仅剩余卖单库存、精确值、已知股/手单位、有时区的同日快照及截面前可见记录才能生成封单特征；媒体下界等保留证据而不填Q。当前一条标准股份报道不合格，精确封单特征仍为零。

本机联网脚本与请求记录位于[追加目录](../课程视频/情绪股一字跌停开板_20261018/复核_分钟日线与封单/)；`取全部历史分时.py`、`补取分笔与封单.py`使用`pytdx==1.72`，另有BaoStock诊断及公开文档请求。公开节点与接口可用性会变，历史日期必须核对原返回，无法返回不补成当前数据。分析复现只用标准库，另存输出目录可核对输入/源码哈希及CSV；原回放不被覆盖。

### 同花顺MCP再复核

[新增核查脚本](limitdown_ifind_audit.py)只读已归档的同花顺MCP返回、三篇媒体跌停表与原40日核查名单，保持冻结协议和原A/B回放不变。40日160个OHLC字段一致，成交量明确单位重取后相差均不超过1股；媒体金额覆盖原18个观察日中的7日，精确Q仍为零。联明说明金额下降可能主要来自跌停价下降，原11段的次日开盘价均低于开板日收盘价；完整分钟与执行未补齐，不生成策略收益。见[新研究结论](../桃哥模式/情绪股一字跌停后的开板研究.md#十二同花顺接入后再研究补到的数据与新的判断)。

```sh
python3 量化程序/limitdown_ifind_audit.py \
  --study-dir 课程视频/情绪股一字跌停开板_20261018 \
  --research-dir 课程视频/情绪股一字跌停开板_20261018/同花顺MCP再研究 \
  --out 课程视频/情绪股一字跌停开板_20261018/同花顺MCP再研究/复核结果
python3 -m unittest discover -s 量化程序 -p 'test_limitdown_ifind_audit.py'
```

标准库即可运行，11项新增检查使用合成输入，不要求同花顺密钥；完整分析需要本机已归档的数据。`--research-dir/原始返回/`保存MCP工具名、请求、请求与归档时间及完整返回；`媒体原文/`保存原HTML与解析表，`公告原文/`保存PDF及提取文字，另有`请求清单.json`、`工具边界.json`与本地下载脚本。全部数据由Git忽略。

脚本保留带日期的原列名，拒绝把休市填值、最新收盘价、单位未核的量、普通成交额及报道折算股数补成合格输入；输出5份CSV和JSON，另记哈希。媒体中的世嘉4/9不是严格一字，作为对照保留；7条报道不补齐原15:00精确封单，不用媒体发布日期冒充已验证的历史首次可见时间。MCP目前的高频工具只支持当日日内L1，不等于已开通历史分钟或盘口接口。
